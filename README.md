## About the Project

This project is a front-end projects showcase built with React and Vite.  
It displays my completed HTML, CSS, JavaScript and React projects in a clean card layout.

The goal of this project is to practice React component structure, project data management, filtering, searching and responsive UI design.

## Features

- Hero section
- Project cards
- Category filters
- Search input
- Clear search button
- Results count
- Empty state when no projects are found
- Technology badges
- Live Demo and GitHub links
- Responsive design
- Clean component structure

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- Git
- GitHub
